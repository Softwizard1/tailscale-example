🔒 Internal Service — reachable only over the tailnet

If you can read this, you reached me through Tailscale.

This nginx instance publishes no host port and is not exposed to the public internet. The only path in is the tailnet identity tag:backend, served over HTTPS by tailscale serve.

An ACL allows tag:client to reach me on ports 80/443. tag:dev has no such rule, so it is denied by default.
